Git — распределённая система управления версиями.

Что умеет Git:
- хранит историю изменений каждого файла проекта;
- показывает, кто, когда и что изменил;
- позволяет вернуться к любой прошлой версии;
- даёт вести параллельную работу в ветках и затем объединять их (merge).

GitHub — веб-сервис для хостинга Git-репозиториев и совместной разработки:
pull request'ы, форки, обсуждения, публикация сайтов через GitHub Pages.
